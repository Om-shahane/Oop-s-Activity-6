## 📖 Project Overview

The **Bus Ticket Booking System** is a console-based application developed using C++. It helps users manage bus information, search routes, view available seats, book tickets, cancel bookings, and view ticket details.

This project demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts in C++.

## 🎯 Objectives

- Understand Object-Oriented Programming concepts.
- Implement classes, objects, and inheritance.
- Demonstrate runtime polymorphism using virtual functions.
- Implement file handling to save ticket information.
- Manage bus seats and ticket bookings.
- Apply dynamic pricing and discount calculations.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Compiler:** GCC / MinGW
- **IDE:** Visual Studio Code
- **Concepts:** OOP, File Handling, STL

## ⭐ Features

1. View all available buses.
2. Search buses by source and destination.
3. View bus seat maps.
4. Book bus tickets.
5. Calculate ticket fares dynamically.
6. Apply discounts for eligible passengers.
7. Cancel booked tickets.
8. Calculate cancellation refunds.
9. View ticket details.
10. Save ticket information in text files.

## 📚 OOP Concepts Implemented

| Concept | Implementation |
|---|---|
| Class and Object | Person, Passenger, Bus, Ticket |
| Inheritance | Passenger, ACBus, NonACBus, SleeperBus |
| Encapsulation | Class data and member functions |
| Abstraction | Abstract Person and Bus classes |
| Polymorphism | Virtual and overridden functions |
| File Handling | `ifstream` and `ofstream` |
| STL | Vector and Smart Pointers |
